# Simple Block Theme — Agent Instructions

These instructions apply only to this theme directory and everything beneath it, wherever the theme is opened or installed in a workspace.

Before changing theme code, follow the conventions in [`DEVELOPER-STANDARDS.md`](DEVELOPER-STANDARDS.md). That document is the single source of truth for the theme’s architecture, PHP, ACF, assets, styles, accessibility, and build/deployment practices. Check project-specific files such as `theme.json`, `functions.php`, and existing blocks rather than assuming values or handles are the same in every installation.

Keep this file as a short entry point; update `DEVELOPER-STANDARDS.md` when the theme’s conventions change instead of maintaining duplicate rule sets.
